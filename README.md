# Case 1 - Análise Estratégica de Vendas (SQL)

Este projeto tem como objetivo analisar o **desempenho comercial e financeiro da base Contoso Retail Data Warehouse**, avaliando **vendas, produtos, categorias e regiões,** com foco na identificação de padrões, **oportunidades de crescimento e otimização de resultados.**

A análise foi conduzida utilizando **SQL Server** para extração, tratamento e consolidação dos dados, aplicando consultas com JOINs, CTEs e funções de agregação. Complementarmente, o **Python** foi utilizado para análise exploratória, manipulação de dados e construção de visualizações que facilitaram a interpretação dos resultados.

O foco do projeto foi aplicar **raciocínio analítico, SQL e visualização de dados** para transformar informações brutas em **insights estratégicos,** apoiando a tomada de decisão baseada em dados.
